## Critical constraint
`VideoChunk.video` is a ForeignKey to `Video`. The `Video` object MUST exist before any `VideoChunk` can be created. We create a **minimal Video stub** before creating any `VideoChunk`.

## Step 6 — `videos/tasks/chunk_tasks.py`

### Helper function 1 — `build_chunk_dedup_item`
Pure function that builds the DynamoDB dict format:
```python
def build_chunk_dedup_item(chunk_hash: str, s3_url: str) -> dict:
    return {
        "chunk_hash": chunk_hash,
        "s3_url":     s3_url,
    }
```

### Helper function 2 — `add_to_bloom_filter`
Pure function that adds a hash to Redis Bloom Filter.
RedisBloom module is already installed — use `BF.ADD` directly:
```python
import redis
from django.conf import settings

def add_to_bloom_filter(chunk_hash: str) -> None:
    client = redis.Redis.from_url(settings.REDIS_URL)
    client.execute_command('BF.ADD', 'bloom:chunks', chunk_hash)
```

### Helper function 3 — `store_in_dynamodb`
Pure function that stores a `ChunkDedupItem` in DynamoDB.
- In `local` environment: log only, do not call DynamoDB
- In all other environments: store in DynamoDB

```python
import logging
logger = logging.getLogger(__name__)

def store_in_dynamodb(dedup_item: dict) -> None:
    from django.conf import settings
    if settings.ENVIRONMENT == 'local':
        logger.info(f"[LOCAL] DynamoDB skip: {dedup_item}")
        return
    import boto3
    dynamo = boto3.resource('dynamodb')
    table  = dynamo.Table('chunk_dedup')
    table.put_item(Item=dedup_item)
```

### Helper function 4 — `ensure_video_stub`
Pure function that creates a minimal Video stub if it does not already exist.
Required because `VideoChunk.video` is a ForeignKey to `Video`.

```python
def ensure_video_stub(video_id: str) -> None:
    from videos.models import Video
    Video.objects.get_or_create(
        id       = video_id,
        defaults = {
            'upload_id':    video_id,
            'total_chunks': 0,
            'status':       'processing',
        }
    )
```

### Celery task — `persist_chunk`

```python
@shared_task(bind=True, max_retries=3)
def persist_chunk(self, video_id, chunk_index, chunk_hash, s3_key, size_bytes):
```

#### Logic in order:
1. Call `ensure_video_stub(video_id)`
2. Persist `VideoChunk` in PostgreSQL:
```python
from videos.models import VideoChunk
VideoChunk.objects.update_or_create(
    video_id    = video_id,
    chunk_index = chunk_index,
    defaults    = {
        's3_key':     s3_key,
        'sha256':     chunk_hash,
        'size_bytes': size_bytes,
    }
)
```
3. Add hash to Bloom Filter via `add_to_bloom_filter(chunk_hash)`
4. Build DynamoDB item via `build_chunk_dedup_item(chunk_hash, s3_key)`
5. Store in DynamoDB via `store_in_dynamodb(dedup_item)`
6. On failure, retry with exponential backoff:
```python
except Exception as exc:
    raise self.retry(exc=exc, countdown=2 ** self.request.retries)
```

## Step 8 — `videos/views_upload.py`

### `UploadChunkView` — `POST /api/v1/upload/chunk`

```python
from rest_framework.views import APIView
from rest_framework.response import Response
from rest_framework.parsers import MultiPartParser
from videos.serializers_upload import ChunkUploadSerializer
from videos.services.storage import get_storage
from videos.tasks.chunk_tasks import persist_chunk

class UploadChunkView(APIView):
    parser_classes = [MultiPartParser]

    def post(self, request, *args, **kwargs):
        # 1. Validate
        serializer = ChunkUploadSerializer(data=request.data)
        serializer.is_valid(raise_exception=True)
        data = serializer.validated_data

        # 2. Read blob bytes
        chunk_data = data['chunk'].read()

        # 3. Store blob synchronously via Registry
        s3_key = get_storage().upload(
            chunk       = chunk_data,
            video_id    = data['uploadId'],
            chunk_index = data['chunkIndex']
        )

        # 4. Fire Celery task asynchronously — do NOT await
        persist_chunk.delay(
            video_id    = data['uploadId'],
            chunk_index = data['chunkIndex'],
            chunk_hash  = data['chunkHash'],
            s3_key      = s3_key,
            size_bytes  = data['sizeBytes']
        )

        # 5. Return immediately
        return Response({'status': 'ok'}, status=200)
```
